# 🚀 START GENI (2 Steps)

```bash
cd /Users/yimi/Desktop/GENI

# Install backend
cd backend && npm install && cd ..

# Install frontend
cd frontend && npm install && cd ..
```

**Terminal 1 - Backend:**
```bash
cd /Users/yimi/Desktop/GENI/backend
npm run dev
```

**Terminal 2 - Frontend:**
```bash
cd /Users/yimi/Desktop/GENI/frontend
npm run dev
```
